# KP Recap Myanmar translation Worker\n\nStaging source for Cloudflare Workers AI `@cf/meta/m2m100-1.2b`. It accepts POST `/translate` `{text,source_lang,target_lang:\"my\"}` and responds `{translated_text}`. The Android client sets a HTTPS base URL in Tools.\n\n**Not deployed or active by default.** `workers_dev=false` intentionally prevents accidental public AI-quota spending. Deploy only after confirming authorized Cloudflare billing/quota controls, then restrict access with a production-grade rate limiter (the source provides only per-isolate throttling). The Worker uses an AI binding and does not embed API keys. Calls may consume Workers AI Neurons and are not unlimited.\n\nWhisper speech recognition is local to the Android device; translation runs online. Exact text is sent to Cloudflare when user requests translation.\n
